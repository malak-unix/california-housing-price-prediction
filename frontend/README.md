# PropValue AI frontend

The frontend is the React + Vite presentation layer for the California Housing prediction project. See the repository-level [`README.md`](../README.md) for setup commands, environment configuration, model limitations, map-provider details, and image attribution.

From this directory:

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev
```

Production validation:

```powershell
npm run build
```
